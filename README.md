# Описание программы

**Movie Library** - это библиотека всех просмотренных вильмов, с их рейтенгом и годом.

#Возможнасти

Дабовление вильма.
фильтрация по жанру и году.
просмотр рейтинга.
просмотр названия.

###запуск
Вести python mine.py 
№Пример использывания
1 Заполнить поля в добовлении фильма.
2 Нажать добавить.
3 Заполнить хоть одно поле фильтрация.
4 Нажать применить фильтр.
